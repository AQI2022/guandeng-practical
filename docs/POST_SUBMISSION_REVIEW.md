## 做了什么

- 给在线检查增加输入版本和请求时的任务编号快照。用户在请求返回前修改工单或任一字段，迟到结果就会作废；标题只使用本次请求编号。增加十秒超时提示，避免失败时误显示旧结论。
- API 拒绝布尔值电量/温度，并验证与表单一致的设备类型要求。解析深嵌套 JSON 返回受控错误，后续正常请求继续可用。
- 联合选择阈值和车间范围，采用 `90 × q × 已知失败提示数 − 复核成本 × 全部提示数`；未知结果提示只计工作量，不计效果收益。保留情景敏感性输出及每车间盈亏平衡信息。当前 q=.5、10 分钟时规则仍是 >15 分钟的一/三/四号；不同 q 与成本假设可能选出不同范围。
- 分析入口固定本题 2026-09-01 至 09-07 七日范围，并拒绝越界或缺少自然日的输入；年龄分桶保留 46 分钟以上数据；来源报告文件使用实际输入 basename。
- 页面和提示文案改为“距末次成功拉取”，明确其不代表设备测量本身新鲜；补充按车间查看情景盈亏临界点。
